    Migration Readiness Scorecard — Demo — Patents RAG¶

    Copied verbatim from the repository

    Source: artifacts/results/scorecard_widened.md

    How we got here — not the recommendation. The same six gates at n=70 with incumbent Claude Sonnet 5 (via Vertex partner models) claude_baseline and candidate Gemini 2.5 Flash (development generation) gemini_tuned_v1. Every row of the frozen artifact below is those two models and no others. This is the run the adaptation ladder was built on; the prompts it produced were then run unchanged on the deployment generation above.

    Rendered 2026-08-11 and left frozen. Its cost cells read prices unverified because that was true when it was rendered; prices cleared on 2026-08-12, which is why the deployment card carries measured corpus costs and this one does not. Re-rendering it today would also move Feature Extractor from 3 of 6 gates to 4 of 6 on an instrument that did not exist on 11 Aug. New measurements go in new files, so this one is not re-rendered.

    Refresh with python scripts/build_site.py. Nothing on this page is retyped, rounded or reformatted; every figure came from an executed model call.

    Times in the artifact below are UTC. In Singapore time:

    • 2026-08-09T16:07:15+00:00 — 10 Aug 2026, 12:07 AM (SGT)
    • 2026-08-11T06:20:37+00:00 — 11 Aug 2026, 2:20 PM (SGT)

    REPLAY — every number below comes from model calls recorded 2026-08-09T16:07:15+00:00 to 2026-08-11T06:20:37+00:00, not from a run just now.

    Gates are checked against 95% CI bounds, so a passing gate licenses "quality parity within measurement under pre-agreed gates" — never "zero quality drop".

    Run notes

    • judged on the FULL corpus, not the registered core split: chunk_summarizer, feature_extractor, query_rewriter. Every other subagent is judged on core only, so judged n differs across subagents — see each arm's judge.split and judge.items_scored before comparing judge scores.

    Judge cross-check. Second-judge cross-check: Claude Sonnet 5 re-scored the recorded outputs against the same rubrics — criterion-level agreement with the gated Gemini 2.5 Pro judge: query_rewriter 98.8% (kappa 0.936, VALIDATED); chunk_summarizer 99.0% (kappa 0.948, VALIDATED); feature_extractor 92.9% (kappa 0.758, VALIDATED). The Gemini 2.5 Pro judge is the gated instrument and was registered before results were seen. The Claude cross-check judge validates it. The two are never averaged and one is never substituted for the other.
